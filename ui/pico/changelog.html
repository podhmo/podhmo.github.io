v2.4.0

2026-10-01

CLI の検索コマンドが O(log2n) になりました1。 ショートカットは Ctrl+K です。 旧コマンド find は廃止され、search に統一されました。 詳細は マイグレーションガイド か GitHub の Issue を参照してください。

既知の問題: Windows 環境で検索インデックスの再構築に時間がかかる場合があります。

変更点

  • 追加 検索インデックスの差分更新
  • 削除 --legacy-index フラグ
$ app search --reindex
index: rebuilding... done (12,841 docs in 1.2s)
$ app status
index: up to date
1 既存インデックスからの増分更新時の計算量。 ベンチマーク結果
