ウェブアプリUI例集

pico.css v2 のコンポーネント組み合わせだけで作る例。独自クラス・独自CSSはなし。モバイル最優先。

page 使いどころと主な部品
login 認証フォーム — article, form, role="switch", aria-invalid
hero ランディングページ — nav, hgroup, role="group", blockquote
dashboard KPIダッシュボード — .grid, article, table.striped, progress, dropdown
datatable 管理用データテーブル — role="search", dropdown の一括操作, table.striped (モバイル向けに列を畳む), ページネーション
tasks タスク管理 — checkbox リスト, progress, role="group"
kanban カンバンボード — .grid 3列, 入れ子 article
chat メッセージング — aside nav, details アコーディオン, role="group"
settings 設定フォーム — role="switch", range, select, dialog (modal)
profile プロフィール詳細 — .grid 2列, figure, table
inbox 受信トレイ・通知一覧 — nav タブ風, article リスト, kbd ラベル
billing 料金プラン・請求履歴 — .grid 3カード, mark バッジ, table
ai-studio-download 実アプリのモック (chatgpt/tools/ai-studio-download) — article + .grid でカード内を2列化, role="group" の操作ボタン, aria-busy

各ページはそのまま雛形としてコピーできる。使い分けの指針は README.md を参照。
